# 不撞场｜2026 筹款人交流会参会助手

**[打开参会页面](https://rae-gu.github.io/fundraiser-2026-guide/)** · [GitHub 项目地址](https://github.com/Rae-gu/fundraiser-2026-guide) · [产品案例与复盘](./CASE_STUDY.md)

## 写在前面

一直到临近开会，我才终于决定要去参加今年的筹款人交流会。

决定得有点晚，接下来就遇到了一个小问题：大会有好多平行分会场，还有圆桌、夜谈、工作坊等不同活动，相关介绍和通知散落在一篇篇公众号推文里。有的活动还得单独报名，甚至需要申请或审核。

每篇推文单独看都挺详细，但要让我一下子搞清楚**哪场什么时候开始、哪些同时举行、我到底想去哪个、需不需要提前报名**，就有点困难了。（主要是我自己的问题，最近实在没有那么多脑容量来回切文章、对日程。）

于是我干脆给我的 AI 派了个活：把这些公开信息整理在一起，按时间排好，标出撞场和参与门槛，最好还能让我勾选感兴趣的场次，最后生成一份自己的参会安排。

整理着整理着，就有了这个小网页——**「不撞场」**。

它一开始只是我给自己做的参会小工具。如果刚好也有其他参会伙伴跟我一样，面对一串公众号推文有点不知道从哪看起，欢迎直接拿去用。希望大家可以少花一点时间对日程，多留点精力给现场真正想听的讨论、想认识的人。

> **先说明一下：** 这是我借助 AI 整理的**个人、非官方参会工具**，不是大会主办方发布的议程或报名系统，也不用于商业用途。信息来自公开渠道，可能存在遗漏、识别错误或临时调整。具体时间、地点、参与条件及报名结果，**一律以主办方最新通知为准**。

## 这个页面可以帮你做什么？

简单来说，就是把「找信息 → 选场次 → 查撞场 → 确认报名 → 整理自己的日程」放到一个页面里。

| 我想知道 / 想做的事 | 去哪里看 |
| --- | --- |
| 这个时间段都有哪些活动？ | **按时段选场**：集中比较不同议题，看简介、时间和原文 |
| 两场都想去，会不会撞时间？ | **时间总览**：查看同一时间的安排，以及所选场次的冲突提醒 |
| 感兴趣，但还没想好去不去 | 给场次标记 **「想去」**，之后再决定是否 **「计划参加」** |
| 有门票就能进吗？是不是还要预约？ | **报名门槛**：看单独报名、申请审核、人数限制或待核实的提示 |
| 我已经报过名了吗？ | 在场次中记录 **尚未报名 / 已提交待确认 / 已获得确认** 等个人进度 |
| 最后两天怎么安排？ | **我的参会安排**：汇总选择、复制清单、分享安排，或导出日历 |
| 这条信息是哪篇推文说的？ | **原文资料**：保留公众号链接、核对笔记和相关信息出处 |

另外，如果发现公众号又有新通知，也可以自己补充或修改场次信息，不用重新画一遍日程表。

## 怎么用？我建议这样选

1. **先随便逛逛。** 打开[参会页面](https://rae-gu.github.io/fundraiser-2026-guide/)，从「按时段选场」开始。看着感兴趣的先点「想去」，确定优先级后再点「计划参加」。
2. **看看有没有撞场。** 去「时间总览」或者「我的参会安排」，检查你选中的活动有没有重叠。遇到同时段的场次，就只能忍痛做选择了。
3. **别忘了查报名条件。** 有些活动不是持大会门票就能直接参加。打开「报名门槛」，回到原文或主办方指定入口完成报名，再手动记录自己的状态。**页面里的「计划参加」不等于报名成功。**
4. **带着自己的安排去参会。** 到「我的参会安排」复制一份清单、生成分享链接，或者把有完整起止时间的已选活动导出成 `.ics` 日历文件。

电脑和手机都能打开，不用注册或下载 App。

## 信息整理到哪里了？

目前按照 **2026 年 10 月 20 日** 已收集的公开资料整理，主要包括：

- **8 场平行分会场**及已公布的时间段；
- 筹款人夜谈、AI 工作坊、圆桌咨询、同行者市集等其他活动；
- 收集的 **16 篇公众号文章**，保留对应的原文链接与整理摘要；
- 部分活动的单独报名、遴选、限额等参与要求。

但这还不是一份百分之百完整的最终议程：**部分图片中的二维码、具体会议室、完整主论坛安排、报名截止时间和剩余名额**等信息，仍有待进一步核实。页面会把未确认的内容标出来，而不是默认它们没有限制。

主要公开参考资料：[大会介绍](https://www.cafpnet.cn/sys-nd/312.html) · [平行分会场预告](https://www.cafpnet.cn/sys-nd/314.html) · [圆桌咨询相关信息](https://www.cafpnet.cn/sys-nd/313.html)。其他公众号原文见网页中的「原文资料」。

## 还有几件事，使用前最好知道

- **这不是报名系统。** 页面只是帮你整理选择和记录进度；是否真正获得参会资格，要看主办方的确认。
- **个人选择保存在你的浏览器里。** 收藏、报名状态、补录的场次和笔记使用本地存储（`localStorage`），不会自动同步到另一台手机或电脑。清除浏览器网站数据后也可能丢失。
- **补录内容不会自动同步给所有人。** 你在网页上修改的场次只对当前浏览器生效。如果公开信息需要纠正，需要把修改更新到 GitHub 仓库后重新发布。
- **分享前留意隐私。** 「分享我的安排」会把你选择的场次及相关内容放进分享链接里。如果自行补录了私人信息，请不要直接分享。
- **看不到冲突，不代表一定不撞。** 没有完整日期和起止时间的活动，暂时无法参与自动冲突检测。

## 如果你也想帮忙完善

如果发现某场时间有变、报名入口失效，或者有我遗漏的活动，欢迎通过 [GitHub Issues](https://github.com/Rae-gu/fundraiser-2026-guide/issues) 提醒我，最好附上对应的公众号文章或官方通知链接，方便核对。

项目本身很简单：用原生 HTML、CSS 和 JavaScript 做的静态页面，主要代码和内置数据都在 [`index.html`](./index.html) 中，没有单独的服务器和数据库。

想自己运行的话，克隆仓库后在浏览器中打开 `index.html` 即可：

```bash
gh repo clone Rae-gu/fundraiser-2026-guide
```

如果要更新面向所有人的公开内容，需要修改并提交仓库中的 `index.html`，再由 GitHub Pages 重新发布；**请不要把个人报名记录提交到公开仓库**。
