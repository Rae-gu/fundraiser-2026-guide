# 不撞场 · 2026筹款人交流会参会助手（更新版）

当前版本：2026-10-20；个人整理、非官方产品。主办方确认大会为 2026 年 10 月 23—24 日在上海举行，设置 8 个平行分会场。能从主办方网站核实的具体议题目前为 3 场；还有圆桌咨询，具体排期、场地与报名资格不能全部确认。

## 此次新增功能

- 参与方式单独分类：待核实、持大会资格可参加、需另行报名预约、需申请审核邀请、报名已截止/满额。
- 每场可记录报名条件、截止时间、名额/资格限制、报名原文或申请链接。
- 每场可以独立标记个人报名状态（尚未核对、尚未报名、已提交/待确认、已获确认、确认无需另报），与「想去/计划参加」分离。
- 「报名门槛」看板优先显示已选但仍需要检查资格的场次。
- 完整保存用户 2026-10-20 发送的 16 篇微信公众号链接，提供打开原文、标记已读、编辑笔记、关联已有场次和从文章新建场次的功能。
- 保留原先的按日期筛选、议题收藏、冲突检测、个人计划与日历导出功能。

## 重要的信息边界

这 16 个公众号页面在当前网页访问环境中不能直接读取，搜索引擎没有找到可靠的全文。因此全部标记为「正文待核对」，不擅自添加会议名称、场次时间、人数、截止日期或预约规则。链接是一条线索，不代表一场独立会议，避免重复计数。

请在微信中打开原文后，将关键页面截图或文字提供给编辑者，才能核实细节并更新所有人的公共议程。用户本人也可以在页面内临时补录；但本地笔记和报名进度不会自动同步到 GitHub。

## 如何使用

直接打开 `index.html` 即可使用，不依赖后端。适配手机与桌面。数据保存在当前浏览器 localStorage，若删除浏览器数据则可能丢失；使用「分享我的安排」不会包含本地的私人报名进度。

## 如何发布

仓库已创建且 `index.html` 已上传至根目录。然后在仓库 Settings > Pages 里设置 Deploy from a branch，main / (root)。部署完成后网页将通常位于 `https://<GitHub用户名>.github.io/fundraiser-2026-guide/`。

页面已上传至 Rae-gu/fundraiser-2026-guide 的 main 分支。还需在 GitHub Settings > Pages 中启用从 main 分支根目录发布。
